# TWRP Theme Studio

A lightweight web‑based editor for customizing the Android recovery UI theme (TWRP). It loads the XML theme files from the local `android_bootable_recovery` source tree, provides a full‑screen preview, and lets you edit colors, shapes, and images via a floating edit button.

## Features
- Full‑screen preview matching the Realme C51 resolution (720×1600).
- Floating circular **Edit** button that opens a panel with:
  - Color pickers for each `<color>` entry.
  - Image upload fields for `<image>` assets.
  - Sliders for shape/size adjustments.
- Live preview updates instantly.
- **Save to source** writes the updated XML and image assets back to the cloned `android_bootable_recovery` repository and commits the changes.
- Simple to run with Node.js (`npm install && npm start`) or Python (`python -m http.server`).

## Quick Start
```bash
# Clone this repo (you can skip if already created)
git clone https://github.com/CodeVortax/twrp-theme-studio.git
cd twrp-theme-studio

# Install dependencies (Node) or just use the static server (Python)
npm install   # optional, no dependencies required currently
npm start     # runs a simple http-server on port 8080
# or
python -m http.server 8080
```
Open `http://localhost:8080` in the phone's browser (Termux forwards localhost).

## How It Works
1. The app fetches the theme XML files (`gui/theme/portrait_hdpi/ui.xml` and `gui/theme/common/portrait.xml`) from the recovery source directory.
2. `themeParser.js` converts XML nodes into a DOM representation using CSS variables for colors and `<img>` tags for images.
3. The preview container renders the DOM, scaled to the device size.
4. The edit panel lets you modify values; changes are reflected in the preview immediately.
5. When you click **Save**, the modified XML strings are written back to the source tree, images are saved, and a git commit is created and pushed.
